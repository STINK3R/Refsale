# RefSale: поиск, Метрика и промпты для картинок

## 1. Яндекс Метрика (п. 7)

1. Зайти на https://metrika.yandex.ru → «Добавить счётчик».
2. Адрес сайта: `refsale.ru`. Включить «Вебвизор, карта скроллинга, аналитика форм», если нужно смотреть записи действий.
3. Код счётчика вставлять в сайт не нужно. Скопировать номер счётчика (цифры, например `98765432`).
4. В админке: вкладка «Контакты, FAQ, Метрика», раздел «Яндекс Метрика». Вставить номер, при желании отметить «Вебвизор», нажать «Сохранить».
5. Счётчик включится при следующей загрузке страниц. Каждый переход по сайту считается отдельным просмотром.

## 2. Яндекс и Google: чтобы сайт находился (п. 6)

На сайте уже готово:

- заголовки и описания страниц: главная, каталог, каждая категория и форум;
- у каждой категории свой адрес (`/catalog?c=3`) и своя строка в карте сайта;
- `https://refsale.ru/sitemap.xml` собирается из категорий в базе;
- `https://refsale.ru/robots.txt` закрывает личные страницы. Для Яндекса в нём ещё указано, что `?promo=` и `?ref=` — те же страницы (иначе каждая реферальная ссылка считалась бы дублем);
- данные об организации для поисковиков (JSON-LD) с названиями «RefSale» и «РефСейл»;
- картинка для ссылок в мессенджерах и соцсетях: `og-image.jpg`, 1200×630.

Что сделать самим, один раз.

### Яндекс Вебмастер — https://webmaster.yandex.ru

1. «Добавить сайт» → `https://refsale.ru`.
2. Подтвердить права. Проще всего через DNS: добавить у регистратора домена TXT-запись, которую покажет Яндекс. Можно и HTML-файлом: прислать мне этот файл, я положу его в `frontend/public/`.
3. «Индексирование» → «Файлы Sitemap» → добавить `https://refsale.ru/sitemap.xml`.
4. «Индексирование» → «Переобход страниц» → добавить главную и `/catalog`.
5. «Информация о сайте» → «Регион сайта»: Россия.
6. Метрику связать с Вебмастером: «Настройки» → «Привязка к Яндекс Метрике».

### Google Search Console — https://search.google.com/search-console

1. «Добавить ресурс» → «Доменный ресурс» → `refsale.ru`.
2. Подтвердить через TXT-запись в DNS (Google покажет её текст).
3. «Файлы Sitemap» → `sitemap.xml`.
4. «Проверка URL» → главная → «Запросить индексирование».

### Старая иконка «R» и старый заголовок в выдаче

На сервере уже стоит иконка с сурикатом. Google показывает копию, которую сохранил раньше, и сам обновляет её раз в несколько дней или недель. Чтобы ускорить:

1. Выложить эту партию правок: в ней новый заголовок без слова «блогер» и ссылки на иконки с `?v=3`, после которых браузеры заново скачивают иконку.
2. Search Console → «Проверка URL» → `https://refsale.ru/` → «Запросить индексирование». Заголовок обычно меняется за 1–3 дня, иконка — за 1–3 недели.
3. Яндекс Вебмастер → «Индексирование» → «Переобход страниц» → главная.

Для браузеров иконки заданы во всех нужных размерах: 16/32/48 (`favicon.ico`), 48 и 96 для Google, 120 для Яндекса, 180 для iPhone, 192 и 512 для Android.

В `robots.txt` открыты адреса, с которых страницы берут товары, отзывы и настройки (`/api/store/catalog` и т. п.). Без этого поисковик, который показывает страницу со скриптами, видел бы пустой каталог.

Первые страницы появляются в поиске через 1–3 недели. По названию «RefSale» сайт начнёт находиться раньше, чем по общим запросам вроде «оригинальные духи дешевле». Для общих запросов помогают описания категорий и товаров (их пишет админка), отзывы и внешние ссылки: у лидеров мнений в профилях, в каталогах организаций (Яндекс Бизнес, 2ГИС).

## 5. Персональные данные и cookie: что сделано и что осталось вам

На сайте сделано:

- страницы `/privacy` (политика), `/consent` (согласие отдельным документом, как требует 152-ФЗ с 1 сентября 2025) и `/terms` (условия продажи), ссылки на них внизу каждой страницы;
- при регистрации — отдельная галочка согласия, без неё аккаунт не создаётся (проверяется и на сервере). Письма об акциях — вторая, необязательная галочка; её можно выключить в профиле;
- каждое согласие и отзыв записываются в журнал `ref_consent_log`: время, редакция документа, IP, браузер;
- у аккаунтов, созданных раньше, сайт один раз попросит подтвердить согласие;
- баннер cookie: «Только необходимые» или «Принять все». Яндекс Метрика включается только после «Принять все»; выбор можно поменять ссылкой «Настройки cookie»;
- в профиле есть «Удалить аккаунт и отозвать согласие»: данные удаляются из аккаунта, отзывов, форума и вопросов. Заказы остаются — их нужно хранить для бухгалтерского учёта;
- в отзывах и на форуме покупатель подписан как «Анна К.»: полное имя на публике требовало бы отдельного согласия на распространение;
- вопросы площадке принимаются только от вошедших пользователей, то есть с данным согласием.

Что можете сделать только вы:

1. **Реквизиты.** Админка → «Контакты, FAQ, Метрика» → «Реквизиты для документов»: ИП или организация, ИНН, ОГРН, адрес, почта для обращений. Без них документы недействительны.
2. **Уведомление в Роскомнадзор** об обработке персональных данных (pd.rkn.gov.ru) — до начала обработки. За его отсутствие штрафуют.
3. **Серверы в России.** Базы данных с персональными данными граждан РФ должны храниться в России (ст. 18 ч. 5 152-ФЗ). Проверьте, где ваш хостинг, и впишите его в реквизиты.
4. **Юрист.** Тексты — аккуратный шаблон по 152-ФЗ, Закону о защите прав потребителей и Правилам продажи (ПП № 2463). Перед запуском продаж их стоит показать юристу.
5. **Почтовый сервис.** Когда подключите SMTP, лучше выбрать российский сервис. Иначе письма с адресами покупателей уходят за рубеж, и это нужно описать в политике.
6. **Реклама у лидеров мнений.** Их посты с промокодами — это реклама: нужна маркировка (erid) через оператора рекламных данных (38-ФЗ).
