# RefSale (refsale.ru)

Интернет-магазин оригинальной парфюмерии и ухода с реферальными промокодами лидеров мнений.
Проект — отдельная копия сайта кооператива (`D:\1Kooperativniy`) с убранными функциями кооператива.
Стек тот же: Flask + PostgreSQL + React/Vite, всё в Docker.

## Как устроено

**Цены.** У товара две цены: обычная (`price`) — её видят все — и цена по промокоду (`promo_price`).
После ввода любого активного промокода на всём сайте показывается было/стало.
Цена по промокоду не уходит в публичный каталог: её выдаёт только `/api/store/promo/validate`.
Итог заказа сервер всегда пересчитывает сам.

**Промокоды.** Промокоды хранятся в таблице `ref_promos`. У каждого есть лидер мнений, вознаграждение за выданный заказ, лимит и срок действия.
Каждый можно включить или выключить, а общий выключатель — `coop_settings.ref_promos_enabled`.
Реферальная ссылка имеет вид `https://refsale.ru/?promo=КОД`: код применится сам.

**Заказ.**
1. Покупатель оформляет заказ, и он получает статус `new`.
2. Сразу открывается чат с менеджером.
3. Когда пришла предоплата, админ жмёт «Подтверждено».
4. Статус меняется на `accepted`, покупателю уходит письмо, и дальше идут статусы `processing → shipping → done`, плюс `cancelled`.
5. Чат закрывается только на `done` или `cancelled`.

**Лидер мнений.** У аккаунта стоит флаг `coop_users.is_leader`. Он появляется сам, когда админ привязывает к человеку промокод, или его отмечают на вкладке «Лидеры мнений».
- Кабинет находится на `/cabinet`. Там видны промокоды, заказы, вопросы покупателей, начисленное и ожидаемое вознаграждение.
- Имена покупателей в кабинете сокращены.
- Писать в чатах и менять статусы лидер может, только если админ включил «может писать» (`leader_can_write`). По умолчанию это выключено.

**Категории — отдельные страницы.** Вкладки категорий стоят под логотипом (например, «Парфюмерия», «Еда», «Доставка из Китая»).
Вкладка меняет всю главную: фото, подпись, слоган, текст под кнопкой «Как это работает», товары с подкатегориями и отзывы.
Всё это заполняется в окне редактирования категории. Там же задаются два магазина для сравнения цен: по умолчанию Золотое Яблоко и Рандеву.

**Цвет страницы.** У каждой категории свой акцентный цвет (`accent_color`): в него окрашены карточка с фото, активная вкладка и подложки товаров.
Цвет задаётся в окне категории в админке, там же есть кнопки с цветами палитры.
Картинки первых экранов для «Ухода», «Еды» и «Китая» лежат в `frontend/public/img/hero-*-{640,1000,1400}.webp`, исходники — в `img/`.
Проставить цвета и картинки категориям, где эти поля ещё пустые:

```bash
docker compose exec -T backend python - < scripts/set_category_looks.py
```

**Сравнение цен.** У товара и у каждого его варианта есть две цены «в других магазинах». На сайте они показываются зачёркнутыми под нашей ценой.

**Объёмы и упаковки.** Варианты товара (`ref_product_variants`) — например, «50 мл, тестер». У каждого своя цена, своя цена по промокоду и свои цены для сравнения.
Если варианты есть, покупатель выбирает один в карточке товара, и в корзине каждый вариант — отдельная строка.
Цены вариантов по промокоду, как и цены товаров, выдаёт только `/api/store/promo/validate`.

**Дизайн.** Яркий светлый лендинг: кремовый фон, жёлтые кнопки и плашки, чёрный текст, розовый — для скидок и промокода.
Заголовки набраны шрифтом Unbounded. Цвета заданы переменными в `frontend/src/index.css`.

**Главная страница категории** идёт в порядке из ТЗ: фото категории, плашка промокода, слоган, кнопка «Как это работает», поиск и товары, отзывы, «О нас», контакты.

**Маскот — сурикат в жёлтой толстовке** (`frontend/src/components/mascot`, картинки — `frontend/public/mascot/<поза>.webp` и `@2x`).
- На компьютере выглядывает у курсора и подпрыгивает при клике.
- На телефоне выпрыгивает в точке касания, по очереди машет или прыгает.
- Выходит с репликой, когда применён промокод (в очках) и когда оформлен заказ (прыжок).
- Сидит в меню (палец вверх) и в пустых состояниях: корзина — тележка, избранное и отзывы — сердце, заказы — коробки, чат — телефон, форум и кабинет — ноутбук, «ничего не нашлось» и 404 — задумался.

Если у посетителя включено «уменьшить движение», остаются только выходы с репликой.
Чтобы показать полную версию на такой машине, выполните в консоли браузера `localStorage.refsale_mascot = 'on'`.
Исходные PNG поз и картинок первых экранов лежат локально в `img/` и в git не входят.

**Промокод внизу.** Когда плашка на первом экране уезжает, внизу слева появляется кнопка «Есть промокод?» (или розовая «Промокод КОД»). По нажатию она раскрывается в поле ввода (`PromoDock`).

**Скорость.** Шрифты (Golos Text, Unbounded) подключены из пакетов `@fontsource`, а не с Google. Главная картинка предзагружается. Картинки и маскот кэшируются на 7 дней.

**Избранное** — `/favorites`. Список хранится в браузере, аккаунт не нужен.
Вверху страницы видно, до какой даты действует введённый промокод, или поле, чтобы его ввести.

**Регистрация.** Аккаунт создаётся мгновенно: имя, email и пароль, без подтверждения администратором.
Аккаунт нужен для заказа и для вопроса продавцу, потому что в нём живут чаты и статусы.

## Админка — `/admin`

- «Магазин RefSale»:
  - Заказы и чаты с кнопкой «Подтверждено».
  - Промокоды лидеров.
  - Лидеры мнений.
  - Цены (обычная и по промокоду).
  - Контакты сайта: две пары, рабочая и административная. В каждой телефон, почта, Telegram, WhatsApp и MAX.
- «Каталог» — товары, фото, категории, покупатели, отзывы, администраторы.
  - В окне товара: цена по промокоду, цены в двух магазинах для сравнения, объёмы и упаковки.
  - В окне категории: фото, слоган, «Как это работает», магазины для сравнения, порядок вкладок.
  - В таблице отзывов: на странице какой категории показывать отзыв.
- «Поддержка» — вопросы покупателей. «Форумы» — модерация общего форума.

## Локальный запуск

```bash
docker compose -f docker-compose.local.yml up -d --build
```

Сайт откроется на http://localhost:8090, админка на http://localhost:8090/admin.
Логин `admin`, пароль задаётся переменной `ADMIN_PASSWORD`, локально по умолчанию `admin12345`.
Демо-каталог только для локальной базы:

```bash
docker compose -f docker-compose.local.yml exec -T db psql -U coop -d coop < db/demo_seed.sql
```

Тестовые лидеры, промокоды и заказы, затем страницы категорий, объёмы и цены для сравнения (каждый скрипт срабатывает один раз):

```bash
docker compose -f docker-compose.local.yml exec -T backend python - < scripts/demo_seed.py
```

```bash
docker compose -f docker-compose.local.yml exec -T backend python - < scripts/demo_seed_pages.py
```

Фронтенд с горячей перезагрузкой: в `.env.development.local` пропишите `API_PROXY=http://localhost:5001`, затем `npm --prefix frontend run dev`.

## Продакшен

RefSale живёт на одном сервере с кооперативом. Порты 80 и 443 держит nginx кооператива (`/opt/1Kooperativniy`):
он выпускает и хранит сертификат `refsale.ru`, принимает HTTPS и проксирует запросы в nginx RefSale
через общую Docker-сеть `edge`. Сам RefSale наружу портов не открывает.

1. DNS: A-записи `refsale.ru` и `www.refsale.ru` на IP сервера.
2. Сертификат (порт 80 уже отдаёт ACME-проверки из `/var/www/certbot`):
   `certbot certonly --webroot -w /var/www/certbot --cert-name refsale.ru -d refsale.ru -d www.refsale.ru`.
3. Кооператив: `cd /opt/1Kooperativniy && git pull && docker compose up -d --build frontend`.
   Это создаёт сеть `edge` и включает vhost `refsale.ru`. Пока RefSale не запущен, refsale.ru отвечает 502, кооператив работает.
4. `git clone https://github.com/STINK3R/Refsale.git /opt/refsale && cd /opt/refsale && cp .env.example .env`,
   затем заполнить `.env`: `SERVER_SECRET`, `POSTGRES_PASSWORD`, `DATABASE_URL`, SMTP, `ADMIN_PASSWORD`.
   Токен Telegram-бота нужен свой, не кооператива.
5. `docker compose up -d --build`.
6. При первом запуске свежей базы применяются `db/init.sql` и миграции из `db/`. Демо-данных в продакшен-базе нет. Таблицы и колонки магазина бэкенд создаёт сам при старте.

Обновление: `cd /opt/refsale && git pull && docker compose up -d --build`.
