# RefSale (refsale.ru)

Интернет-магазин оригинальной парфюмерии и ухода с реферальными промокодами лидеров мнений.
Проект — отдельная копия сайта кооператива (`D:\1Kooperativniy`) с убранными функциями кооператива.
Стек тот же: Flask + PostgreSQL + React/Vite, всё в Docker.

## Как устроено

**Цены.** У товара две цены: обычная (`price`) — её видят все — и цена по промокоду (`promo_price`).
После ввода любого активного промокода на всём сайте показывается было/стало.
Цена по промокоду не уходит в публичный каталог: её выдаёт только `/api/store/promo/validate`.
Итог заказа сервер всегда пересчитывает сам.

**Промокоды.** Промокоды хранятся в таблице `ref_promos`. У каждого есть лидер мнений, вознаграждение за выданный заказ, лимит и срок действия.
Каждый можно включить или выключить, а общий выключатель — `coop_settings.ref_promos_enabled`.
Реферальная ссылка имеет вид `https://refsale.ru/?promo=КОД`: код применится сам.

**Заказ.**
1. Покупатель оформляет заказ, и он получает статус `new`.
2. Сразу открывается чат с менеджером.
3. Когда пришла предоплата, админ жмёт «Подтверждено».
4. Статус меняется на `accepted`, покупателю уходит письмо, и дальше идут статусы `processing → shipping → done`, плюс `cancelled`.
5. Чат закрывается только на `done` или `cancelled`.

**Лидер мнений.** У аккаунта стоит флаг `coop_users.is_leader`. Он появляется сам, когда админ привязывает к человеку промокод, или его отмечают на вкладке «Лидеры мнений».
- Кабинет находится на `/cabinet`. Там видны промокоды, заказы, вопросы покупателей, начисленное и ожидаемое вознаграждение.
- Имена покупателей в кабинете сокращены.
- Писать в чатах и менять статусы лидер может, только если админ включил «может писать» (`leader_can_write`). По умолчанию это выключено.

**Регистрация.** Аккаунт создаётся мгновенно: имя, email и пароль, без подтверждения администратором.
Аккаунт нужен для заказа и для вопроса продавцу, потому что в нём живут чаты и статусы.

## Админка — `/admin`

- «Магазин RefSale»:
  - Заказы и чаты с кнопкой «Подтверждено».
  - Промокоды лидеров.
  - Лидеры мнений.
  - Цены (обычная и по промокоду).
  - Контакты сайта: две пары, рабочая и административная. В каждой телефон, почта, Telegram, WhatsApp и MAX.
- «Каталог» — товары, фото, категории, покупатели, отзывы, администраторы. Цена по промокоду есть и в форме товара.
- «Поддержка» — вопросы покупателей. «Форумы» — модерация общего форума.

## Локальный запуск

```bash
docker compose -f docker-compose.local.yml up -d --build
```

Сайт откроется на http://localhost:8090, админка на http://localhost:8090/admin.
Логин `admin`, пароль задаётся переменной `ADMIN_PASSWORD`, локально по умолчанию `admin12345`.
Демо-каталог только для локальной базы:

```bash
docker compose -f docker-compose.local.yml exec -T db psql -U coop -d coop < db/demo_seed.sql
```

Фронтенд с горячей перезагрузкой: в `.env.development.local` пропишите `API_PROXY=http://localhost:5001`, затем `npm --prefix frontend run dev`.

## Продакшен

1. DNS: A-записи `refsale.ru` и `www.refsale.ru` на IP сервера.
2. `git clone … /opt/refsale && cd /opt/refsale && cp .env.example .env`, затем заполнить `.env`: `SERVER_SECRET`, `POSTGRES_PASSWORD`, `DATABASE_URL`, SMTP, `ADMIN_PASSWORD`.
3. Порты 80 и 443 сейчас занимает nginx кооператива. Смена домена делается одним окном:
   - остановить фронтенд кооператива (`docker compose stop frontend` в `/opt/1Kooperativniy`);
   - выпустить сертификат: `sudo bash scripts/setup-cert-renewal.sh` (он поднимет фронтенд RefSale);
   - `docker compose up -d --build`.

   Если оба сайта нужны одновременно до переезда, задайте в `.env` `HTTP_PORT` и `HTTPS_PORT` и проксируйте на них с основного nginx.
4. При первом запуске свежей базы применяются `db/init.sql` и миграции из `db/`. Демо-данных в продакшен-базе нет. Таблицы и колонки магазина бэкенд создаёт сам при старте.
